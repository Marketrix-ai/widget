🚀 Marketrix Widget Example

This page demonstrates the Marketrix In-App Support Widget. The widget should appear as a floating button in the bottom-right corner.

Note: This is a demo with mock data. In production, you would need valid marketrix-id and marketrix-key values.

Demo Controls

Usage Examples

1. Script Tag Method

<script src="dist/marketrix-inapp.umd.cjs" data-marketrix-id="your-marketrix-id" data-marketrix-key="your-marketrix-key" data-position="bottom-right" data-theme="light" data-avatar-url="https://example.com/avatar.jpg" data-agent-name="Support Agent" data-enabled-modes="show,tell,do"> </script>

2. Programmatic Method

// Load the widget const script = document.createElement('script'); script.src = 'dist/marketrix-inapp.umd.cjs'; script.onload = function() { // Initialize the widget MarketrixInApp.initMarketrixWidget({ marketrixId: 'your-marketrix-id', marketrixKey: 'your-marketrix-key', position: 'bottom-right', theme: 'light', avatarUrl: 'https://example.com/avatar.jpg', agentName: 'Support Agent', enabledModes: ['show', 'tell', 'do'] }); }; document.head.appendChild(script);

3. ES Module Method

import { initMarketrixWidget } from './dist/marketrix-inapp.js'; initMarketrixWidget({ marketrixId: 'your-marketrix-id', marketrixKey: 'your-marketrix-key', position: 'bottom-right', theme: 'light', avatarUrl: 'https://example.com/avatar.jpg', agentName: 'Support Agent', enabledModes: ['show', 'tell', 'do'] });

Features Demonstrated

  • Show Mode: Ask the agent to show you how to do something
  • Tell Mode: Ask the agent to explain something
  • Do Mode: Ask the agent to perform actions for you
  • Theme Switching: Toggle between light and dark themes
  • Position Changing: Move the widget to different corners
  • Responsive Design: Works on all screen sizes
