🚀 Marketrix In-App Support Widget Demo

This is a demo page showcasing the Marketrix In-App Support Widget. The widget should appear as a floating button in the bottom-right corner of the screen.

Note: This is a demo with mock data. In a real implementation, you would need valid marketrix-id and marketrix-key values.

Features

  • Show Mode: The agent will show you how to do something
  • Tell Mode: The agent will explain something to you
  • Do Mode: The agent will perform actions for you
  • Responsive Design: Works on desktop and mobile devices
  • Dark/Light Theme: Supports both themes
  • Customizable: Configurable position, avatar, and agent name

Usage

To use the widget on your website, include the script with your configuration:

<script src="dist/marketrix-inapp.umd.js" data-marketrix-id="your-marketrix-id" data-marketrix-key="your-marketrix-key" data-position="bottom-right" data-theme="light" data-avatar-url="https://example.com/avatar.jpg" data-agent-name="Support Agent" data-enabled-modes="show,tell,do"> </script>

Or initialize it programmatically:

import { initMarketrixWidget } from '@marketrix/inapp-react'; initMarketrixWidget({ marketrixId: 'your-marketrix-id', marketrixKey: 'your-marketrix-key', position: 'bottom-right', theme: 'light', avatarUrl: 'https://example.com/avatar.jpg', agentName: 'Support Agent', enabledModes: ['show', 'tell', 'do'] });

Configuration Options

  • marketrixId (required): Your Marketrix account ID
  • marketrixKey (required): Your Marketrix API key
  • position: Widget position ('bottom-right', 'bottom-left', 'top-right', 'top-left')
  • theme: Theme ('light' or 'dark')
  • avatarUrl: URL to the agent's avatar image
  • agentName: Display name for the support agent
  • enabledModes: Array of enabled modes ('show', 'tell', 'do')

API Integration

The widget communicates with the Marketrix API to send messages and receive responses. Make sure your API endpoints are properly configured to handle the chat functionality.

Demo Mode: Since this is a demo, the widget will show mock responses. In production, it will connect to your actual Marketrix backend.
